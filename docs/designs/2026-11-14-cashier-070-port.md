## What changed

The Cashier is now the reference payment window instead of a dark DanGG dashboard:

- **Light payment surface** (max 780 px) on the dark app shell, with the reference
  balance strip (Balance / P$ / T$ / Ticket), a DanGG Cashier header, and the legal
  footer.
- **Deposit / Withdraw / Transaction History** tabs with the green underline state.
- **Deposit**: Card accordion with Bank Card, Apple Pay and Google Pay radio rows and
  the green **Next** button; E-Wallet accordion (aircash). Next reveals preset amounts
  ($10/$50/$100/$500), a custom amount field, the server deposit limits and the green
  “Add $X” action. It calls the existing idempotent deposit endpoint, so the balance
  really moves and a ledger row is written.
- **Transaction History**: newest-first ledger with currency-aware amounts
  (USD/`P$`/`T$`/GEM), green/red signs and a CSV export.
- **Withdraw**: intentionally disabled with a clear note — DanGG is a play-money room,
  so cash withdrawal is unreachable by design (documented here rather than faked).
- 44 px controls and the same window down to 320 px (2×2 balance grid).
