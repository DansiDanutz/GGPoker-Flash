# My Wallet 040 — reference port

Reference: `docs/screenshots/desk-pass/reference-040.jpg` (Paper screen 040).
Comparison: `docs/screenshots/desk-pass/compare-wallet.png`.

## What changed

- The “My Wallet” account-menu entry now opens a wallet pane inside the My Page window
  instead of jumping to the Cashier page (the reference keeps it in the account window).
- Pane contents follow 040: **Refresh**, a four-card balance row, the **Ticket** row and
  the play-money disclaimer. “Receive chips” and “Get more” link to Rewards.
- Economy mapping (DanGG has no separate Play Money wallet):
  `USD Available → balance`, `Poker Dollar → P$ play_chips`,
  `Tournament Dollar → T$ tickets`, `Play Money → Gems` (violet accent).
- Extra actions at the bottom: Cashier & transactions, Daily freebie.

## Responsive

- ≥1025: four cards in a row, 240 px menu, global rail.
- 768–1024: two-column cards, 200 px menu, rail hidden.
- ≤760: two-column cards, stacked actions, horizontal menu row, 44 px controls.
