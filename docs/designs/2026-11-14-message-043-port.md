# Message 043 — reference port

Reference: `docs/screenshots/desk-pass/reference-043.jpg` (Paper screen 043).
Comparison: `docs/screenshots/desk-pass/compare-msg.png`.

## What changed

- The Message page is now the reference inbox: **Mark All as Read**, a range counter
  (“1-4 of 4”), previous/next paging, one row per notice with its date, and the
  six-month/200-message retention note.
- Notices come from the existing `/api/notifications` model and now carry `created_at`
  for friend requests, unread DMs, tournament registrations and the daily freebie.
- `/api/notifications?all=1` returns **read and unread** items with a `read` flag, so
  Mark All as Read does not erase the inbox; the default endpoint still returns only
  unread items for the badge.
- Rows navigate to the thing they describe (friends, cashier, tournament). The old DM
  threads and lobby feed stay available under a collapsed “Direct messages” section.
- New HTTP test covers the history endpoint and the mark-all-read transition.

## Responsive

- Desktop: 48 px rows, range + pager on the right of the toolbar.
- ≤760: toolbar wraps, 40 px pager buttons, 56 px rows, titles wrap, note at 10.5 px.
