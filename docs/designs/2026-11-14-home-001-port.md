# Poker Home 001–003 — reference port

Reference: `docs/screenshots/live-audit/reference-01-home.jpg` (Paper screen 001),
`01b` (002, TV + Tournaments For You + Special Features) and `01c` (003, Special
Features + Casino + footer) from the captured client library.

Side-by-side: `docs/screenshots/desk-pass/compare.png`.

## What was wrong before

The live Home was a loose approximation: a vector trophy hero, 144 px promo cards with
DanGG text over art, a `DanGG.TV` row made from felt textures, and a table list
immediately below. None of the reference campaign art or card proportions were present.

## What this port does

The Home is now the reference feed, in the reference order and metrics:

| Section | Reference | Port |
|---|---|---|
| Hero | 800×250 campaign creative, centred | Same, `min(1000px, 100% - 130px)`; links to Tournaments |
| For You | 4 creatives, 226×234, 8 px gap | Same creatives at 222×234, 8 px gap |
| TV | 4 cards: 225×140 thumb + title + streamer + viewers | Same thumbnails and card shape; live table name/stakes/seats in the caption |
| Tournaments For You | 3 cards, 345×140 | Same creatives, link to Tournaments |
| Special Features | 4 cards, 225×140 | Same creatives, link to the matching feature |
| Casino | 4 cards, 225×205 | Same creatives, link to Casino |
| Account rail | 112 px | 112 px, labels fit |

Creatives are cropped from the reference screens and served from
`app/public/assets/gg-creatives/`; everything around them (sections, headings, cards,
focus states, rail, tabs) is live HTML. The table browser is no longer on Home — it
belongs to the game tabs, as in the reference.
