## What changed

My Page is now the reference account window instead of the old dashboard:

- **Window tabs**: My Page (active) · Prop Bet · Ocean Rewards · My Promo · Game Settings · close,
  each routed to the real section.
- **Left account menu** (240 px): GGPass Account, My Action Voice, My Game Profile (active red),
  My Wallet, Verify ID, Transaction History, Message, Redeem Coupons, Current Stakers,
  Sellers you follow, PokerCraft, Responsible Gaming, Sign out, plus PokerCraft/Message tiles.
  External items carry the reference ↗ marker; the rest switch the pane.
- **My Game Profile pane**: portrait with VIP badge, nickname field with lock, category chips
  (All, Custom, Poker Players, Ocean Characters, Lucky Charm, Gaming Gods, Historic Figures),
  seven-column avatar grid, Upload Image tile and Apply.
- **20 preset avatars** cropped from the reference into `app/public/assets/avatars/gg-01..20.jpg`
  (`gg-01..06` Poker Players, `gg-07..13` Ocean Characters, `gg-14..20` Lucky Charm).
- **Persistence**: Apply saves the avatar and nickname. `/api/me/avatar` now accepts the
  whitelisted preset paths (`^/assets/avatars/gg-\d{2}\.jpg$`) and stores them as paths;
  arbitrary paths still go through `normalizeAvatar` and are rejected.
- Stakers/Sellers get honest empty panes with a leaderboard link.

## Responsive

- ≥1025: window tabs + 240 px menu + 7-column grid, global account rail on the right.
- 768–1024: 200 px menu, 5-column grid, rail hidden.
- ≤760: horizontal window tabs and menu row, 4-column grid, 44 px controls, pane padding 14 px.
